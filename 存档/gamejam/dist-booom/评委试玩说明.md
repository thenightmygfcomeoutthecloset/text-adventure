# 评委试玩说明

## 游戏入口

解压 ZIP 后，双击 `index.html` 即可在浏览器中打开游戏。

## 如何开始试玩

1. 打开 `index.html`
2. 点击首页的 **「开始试玩」** 按钮
3. 选择故事方向（男频 / 女频）
4. 选择一个感兴趣的世界
5. 创建你的角色（可一键随机生成）
6. 踏入世界，开始冒险

## 是否需要账号

**不需要。** 游戏默认为游客模式，无需注册、无需登录、无需输入 API Key，打开即可试玩。

## 游客模式说明

- 所有游戏进度保存在当前浏览器中
- 关闭浏览器后重新打开，可点击「继续冒险」继续游玩
- 注意：清除浏览器数据会导致存档丢失

## AI 服务说明

本游戏由 DeepSeek 大语言模型驱动 AI 实时叙事。比赛版已内置临时 AI 服务密钥，评委无需自行获取或输入。

## 如果 AI 请求失败怎么办

如果出现「世界突然变得模糊起来……」或「试玩服务暂时不可用」提示：

1. 稍等片刻后刷新页面重试
2. 确认网络连接正常
3. 如果持续失败，可能是内置 AI 密钥额度耗尽，请联系作者

## 推荐浏览器

- Google Chrome（最新版）
- Microsoft Edge（最新版）
- Mozilla Firefox（最新版）

移动端浏览器也可使用，但桌面端体验更佳。

## 是否需要联网

**需要。** 游戏需要连接互联网以调用 AI 叙事服务。除 AI 请求外，不传输任何用户数据。

## 存档说明

- 游戏支持手动存档和自动存档
- 游客模式下存档保存在浏览器本地
- 登录云账号（可选）后可跨设备同步存档
- 评委试玩无需使用云存档功能

## Windows 运行说明

- 双击 `index.html` 在默认浏览器中运行
- 或者右键 `index.html` → 打开方式 → 选择浏览器
- 无需安装任何软件或依赖
