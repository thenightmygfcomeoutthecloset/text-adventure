# 异界卷 · BOOOM GameJam 比赛版

这是为 BOOOM GameJam 提交准备的独立比赛试玩版，与原开发版独立存放，互不影响。

---

## 与原开发版的区别

| 项目 | 原开发版 | 比赛版 |
|------|---------|--------|
| 位置 | 项目根目录 | `gamejam/` |
| API Key | 玩家自行输入 | 内置临时 Key |
| 首页入口 | "开启新篇" | "开始试玩" |
| 游客模式 | 可选 | 默认自动进入 |
| 登录/注册 | 正常显示 | 弱化显示 |
| API Key 输入框 | 显示 | 默认隐藏 |
| 配置文件 | 无 | `config.js` |

---

## 内置临时 AI Key 说明

比赛版通过 `config.js` 内置了临时 DeepSeek API Key，评委无需手动输入即可试玩。

- Key 存储在 `config.js` 中，纯前端无法真正保密
- **比赛结束后请立即在 DeepSeek 平台撤销该 Key**
- 如果 Key 额度耗尽，评委将看到"试玩服务暂时不可用"提示

---

## 游客试玩优先

比赛版默认以游客模式运行：
- 打开 `index.html` → 自动进入游客模式
- 无需注册、无需登录、无需输入 API Key
- 点击"开始试玩"直接开始游戏

---

## 云存档（可选）

登录/注册功能保留但弱化。如果需要跨设备同步存档，可以：
1. 点击首页"登录 / 注册"
2. 使用手机号或邮箱注册
3. 存档将同步到云端

---

## 运行方式

```
双击 index.html
```

或使用 HTTP 服务器：

```
python -m http.server 8080
# 访问 http://localhost:8080
```

无需安装任何依赖或构建工具。

---

## 打包方式

比赛提交用的 ZIP 包已生成：

```
gamejam/booom-text-adventure-submission.zip
```

内容来自 `gamejam/dist-booom/` 目录，只包含比赛必需文件。

---

## 安全提醒

1. **API Key 保护**：`config.js` 中的 Key 在前端代码中可见，任何人都可以查看源码获取。请使用临时 Key，比赛后撤销。
2. **不要提交 service_role key**：ZIP 包中不包含任何管理员密钥。
3. **不要上传原项目**：比赛版是独立副本，不要将整个开发仓库作为提交包。

---

## 比赛结束后

1. 登录 DeepSeek 平台撤销临时 API Key
2. 如需继续对外提供试玩，可恢复手动输入 Key 的方式
3. 删除 `config.js` 中的真实 Key
