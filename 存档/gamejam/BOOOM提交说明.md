## 游戏简介（正式版，不超过 300 字符）

《异界卷》是一款基于AI大语言模型驱动的自由文字冒险游戏。玩家可选择数十个世界（仙侠、科幻、宫斗、克苏鲁、赛博朋克等），创造角色并赋予隐藏命格，自由输入行动与AI实时互动叙事。游戏内置D20命运骰子判定系统、羁绊关系网、成就系统、存档导出等功能。每一次输入都可能触发意想不到的剧情走向——命运在你手中，世界由你书写。

## Windows 运行说明

1. 解压 ZIP 到任意文件夹
2. 双击 `index.html` 即可在浏览器中运行
3. 或者用任意 HTTP 服务器运行（如 `python -m http.server 8080`）

---

## 是否需要联网

**需要联网**。游戏依赖 DeepSeek API 进行 AI 叙事生成。比赛版已内置临时 API Key，打开即玩。

---

## 是否需要账号

**不需要**。比赛版默认为游客模式，无需注册、无需登录。打开浏览器即可开始试玩。

---

## 游客试玩说明

- 点击"开始试玩"进入游戏
- 无需注册、无需登录、无需输入 API Key
- 存档保存在当前浏览器中
- 清除浏览器数据会导致存档丢失

---

## API Key 说明

比赛版已内置临时 DeepSeek API Key，评委无需手动输入。内置 Key 无法真正保密，比赛结束后请在 DeepSeek 平台撤销该 Key。

---

## 存档说明

- 游客模式：存档保存在浏览器 localStorage 中
- 云账号模式（可选）：登录后可同步到 Supabase 云端
- 比赛评委无需使用云存档功能

---

## 推荐浏览器

Chrome / Edge / Firefox 最新版本。移动端也可使用。
