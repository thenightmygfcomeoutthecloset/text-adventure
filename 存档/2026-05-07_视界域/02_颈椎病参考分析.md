# 《颈椎病》参考分析

> 伤官工作室 | Ren'Py | 2026.4 | ~10万字 | 4线7结局 | Steam 85%好评
>
> 这份分析的目的是：**从中提取对我们BOOOMJam作品有用的设计决策**，而不是写评测。

---

## 一、为什么选它做参考

《颈椎病》做完了一件很难的事：**用一个身体病症隐喻，撑起整个社会批判叙事。**

"颈椎病"= 长期低头、被规训、被压弯——是身体对不自由生活的"躯体化"反应。

我们要做的「视界限」本质上是同一类操作：用一个感官/生理层面的限制，折射更大的社会控制体系。

## 二、叙事结构拆解

### 多线互文模型

```
        主线（剥皮杀人魔悬案）
       /      |      \      \
    顾淑芬线  伏愿线   徐亦线  石逢春线(隐藏)
    (控制)   (虚无)   (身份)   (逃离)
       \      |      /      /
        全部拼成完整图景
```

**关键设计**：每条线不是"平行宇宙"，而是同一时间线不同视角/选择。打完一条线你只看到故事的一角，全打完才理解全貌。

**对我们的启发**：
- 如果我们也用多线，每条线可以展示"视界限"在不同阶层/身份下的体现
- 隐藏结局作为"打破视界限"的奖赏

### 叙事节奏

| 阶段 | 内容 | 时长占比 |
|------|------|----------|
| 日常建立 | 警察日常、颈椎病按摩、人物关系铺垫 | ~20% |
| 事件触发 | 玩具厂罢工、剥皮玩偶出现、前女友重逢 | ~15% |
| 多线展开 | 根据选择进入不同角色线，各自深化 | ~50% |
| 收束结局 | 各线独立收束+隐藏结局 | ~15% |

**对我们的启发**：日常部分不要省——它建立了"正常"的基准线，后面的打破才有冲击力。

## 三、UI设计（对Ren'Py的启示）

### 分屏布局
- **左屏**：抽象拼贴插画 / 小地图 / 意象图
- **右屏**：对话文本，流畅如小说阅读
- 没有传统AVG的立绘+对话框断句问题

### NPC表现
- 大多数NPC使用**动物头像/物品图标**代替人脸
- 象征：社会皮囊下的动物本性
- **省美术资源的方式**——这点对Game Jam极其重要

### CG使用策略
- 少量但精准，红色主调统一视觉
- 只在关键情节节点出现，不作为常规叙事手段

**对我们的启发**：
- Game Jam 9天做不了大量立绘 → 学《颈椎病》用符号化/抽象化的视觉方案
- Ren'Py默认UI可以大幅改造，分屏布局技术上可行
- 文字本身的表现力 > 画面

## 四、对我们有用的设计决策参考

### 值得借鉴的

| 做法 | 我们的应用 |
|------|-----------|
| 身体病症→社会隐喻 | 视觉限制→认知/自由限制 |
| 多线互文拼图 | 不同角色视角展示"视界限"的不同侧面 |
| 抽象化角色表现 | 省美术，强化主题表达 |
| 文字本身是主力 | 写好字比画好画更优先 |
| 隐藏结局=真正打破困境 | "打破视界限"作为最终奖赏 |

### 需要注意的教训

| 问题 | 预防 |
|------|------|
| 元素堆砌太多，每条议题都浅尝辄止 | 聚焦1-2个核心议题，挖深不铺广 |
| 主线悬疑弱化，变成"谈恋爱" | 确保核心钩子贯穿始终 |
| 10万字对Game Jam太多 | 控制8000-15000字，30-45分钟流程 |
| UI操作不便、闪退 | 留足测试时间，Ren'Py默认功能够用就别魔改 |

## 五、《颈椎病》的"躯体化"手法

这是《颈椎病》最核心的写作技巧，对我们写「视界限」最关键：

> 颈椎病的痛不是关节劳损，而是被压抑的情绪在身体上找到了出口。——凯博文《苦痛和疾病的社会根源》

**翻译成我们的语境**：
- "视界限"不是眼睛的问题，是被规训的认知在感官上找到了出口
- 主角的"看不清""看不见"= 某种更深层无力的身体表达
- 不要直接说"这个社会很压抑"→ 写"你的视野边缘永远是灰的"
