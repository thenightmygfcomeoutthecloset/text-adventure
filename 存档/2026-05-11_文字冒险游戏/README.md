# 异界卷 · 文字冒险

> 当前版本：v0.7.5「A11y与安全修复」

纯静态前端自由文字冒险游戏。AI 叙事引擎由 DeepSeek Chat API 驱动，支持 Supabase 云端账号跨端同步存档与离线游客模式。

---

## 🌟 核心特色

- **海量世界观设定**：
  - **男频世界**：奇幻仙侠、传统玄幻、武侠江湖、科幻、末日废土、赛博朋克、蒸汽朋克、无限流、都市修真、都市高武、历史古代、赘婿、战神、重生崛起、悬疑灵异
  - **女频世界**：宫斗宅斗、霸总、重生复仇、禁忌情缘、都市异能、西幻史诗、克苏鲁、古言脑洞、玄幻言情、萌宝、年代文、双男主、马甲
  - **自由穿越与定制**：支持上传本地小说 txt 解析世界观并穿越进入，或自由输入背景书写定制世界
- **深度角色塑造与命格系统**：10 种隐藏命格、多维度身世与属性塑造、个性化背景生成
- **D20 命运检定与数值驱动**：动作与风险关键词判定、D20 骰子判定（大失败/失败/成功/大成功）、角色动态数值体系（HP/精力/理智/攻击/防御）
- **沉浸式交互系统**：世界年表动态演进、角色羁绊网络、随身物品交互、成就解锁、足迹地图
- **安全与云端架构**：
  - 本地 API 密钥通过 Web Crypto AES-GCM 高度混淆加密存储，不经过第三方中间服务器
  - Supabase Auth + PostgreSQL 云存档同步，支持手机号/邮箱快速注册，亦支持完全本地免登录的游客模式

## 🚀 快速开始

### 方式一：本地 HTTP 服务运行（推荐）
在游戏目录下运行任意静态 HTTP 服务器以获得最佳的跨端和存储支持：
```bash
# 使用 Python 启动服务
python -m http.server 8080
```
在浏览器中打开 `http://localhost:8080` 即可开始冒险。

### 方式二：浏览器直接双击打开
直接双击 `index.html` 即可在现代浏览器（Chrome / Edge / Safari / Firefox）中直接运行。

## 🎮 游玩流程

1. 打开 `index.html`
2. 输入你的 DeepSeek API 密钥（可随时在 DeepSeek 开放平台获取，密钥仅在本地加密保存）
3. 选择「开启新篇」或点击「登录 / 注册」同步云端档案
4. 选择故事方向（男频 / 女频 / 穿越小说 / 自定义）与目标世界
5. 塑造你的角色、摇取命格并踏入世界
6. 自由输入行动，与 AI 共同谱写你的异界传奇

## 🛠 技术栈与配置指南

- **前端架构**：纯原生 HTML5 / CSS3 / JavaScript (ES6+)，零外部构建依赖，零 npm 安装
- **AI 叙事驱动**：DeepSeek Chat API（用户自备 Key，流式 SSE 生成）
- **云端存档后端**：Supabase Auth + PostgREST (PostgreSQL)

### Supabase 自建/部署注意事项
如需连接自己的 Supabase 项目：
1. 打开 Supabase 控制台的 **SQL Editor**，执行本项目下的 `supabase/schema.sql` 完成建表与 RLS 权限策略初始化；
2. ⚠️ **关键设置**：进入 **Authentication → Providers → Email**，将 **"Confirm email"** 设置为 **OFF（关闭）**，以确保基于虚拟邮箱的手机号快速注册能够免验证直接登录；
3. 将 `游戏.js` 中的 `SUPABASE_URL` 与 `SUPABASE_ANON_KEY` 替换为你自己的项目凭证。
