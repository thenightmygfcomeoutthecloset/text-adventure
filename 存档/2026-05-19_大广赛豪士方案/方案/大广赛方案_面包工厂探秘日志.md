## 二、品牌与命题分析

### 品牌信息

豪士（福建）食品有限公司，创始于 1995 年，总部位于福建漳州。命题核心产品为「豪士藜麦吐司」——研发历时近 4 年，2023 年上市，已登藜麦吐司品类全国销量第一。

**核心卖点**：全球精选原料、高蛋白低热量、没有吐司边、口感松软有嚼劲。

### 命题解读

命题策略单给出两个方向：（一）品牌向「豪士豪士，好吃好吃」；（二）工厂向「用别样形式玩转豪士透明工厂」。

本作品选择**工厂向**。430亩面包工厂、透明玻璃可见自动化流水线、扫码可直播看面包诞生全程——这些素材天然具备「探秘」叙事张力。互动电子书的形式让用户不是被动观看工厂，而是**亲手探索**工厂。

### 竞品差异化

传统食品广告以 TVC、海报、种草短视频为主，消费者看到的是「结果」（成品面包 + slogan）。本作品让消费者**参与过程**——化身一日厂长，走完从原料到成品的完整链路。互动深度决定记忆深度，记忆深度决定转化。

## 三、创意概念

### 核心设定

> **你，收到了豪士工厂的一封神秘邀请函。**
>
> 打开它，你将化身「一日厂长」，推开透明工厂的玻璃大门，亲眼见证一颗藜麦如何穿越全球、历经 12 道工序，最终变成一片 Q 弹拉丝的藜麦吐司。

### 叙事框架

整个体验是一个**第一人称探索旅程**，15 页 = 15 个关卡/场景，用户通过点击、滑动、拖拽等交互推动叙事前进。每页一个「发现」，层层递进。

### 情感曲线

```
好奇心（邀请函）→ 惊叹（全球原料）→ 沉浸（流水线）→ 紧张（质检挑战）
→ 成就感（通关徽章）→ 炫耀（专属海报）→ 行动（购买/直播）
```

## 五、交互设计总览

### 交互类型分布

| 页面 | 交互类型 | 交互动作 | 优先级 |
|------|----------|----------|--------|
| P1 | 点击触发 | 点信封 → 开启动画 | 必做 |
| P2 | 手势滑动 | 左右滑 → 开门 | 必做 |
| P3 | 点击探索 | 点地图光点 → 弹出信息 | 必做 |
| P4 | 滑动 + 点击 | 上滑推进画面 + 点标签看详情 | 必做 |
| P5 | 拖拽滑块 | 调筋度 → 过关（可降级为三档点选） | 核心 |
| P6 | 点击加速 | 点屏幕 → 时间加速 | 必做 |
| P7 | 滑动滑块 | 调温度 → 过关（可降级为三档点选） | 核心 |
| P8 | 横向滑动 | 浏览流水线 | 必做 |

### 交互设计原则

- **每页至少一个交互点**，避免纯阅读页
- **交互即有反馈**（动画/音效/震动），让用户感知到「我做了什么」
- **难度曲线**：前半程轻松探索 → P9 挑战峰值 → 后半程成就感
- **容错设计**：P5/P7/P9 失败不惩罚，鼓励重试

### 翻页系统（H5 版）

```javascript
// main.js 核心逻辑
const pages = document.querySelectorAll('.page');
let current = 0;

function goTo(index) {
  pages[current].classList.remove('active');
  pages[index].classList.add('active');
  pages[index].style.transform = 'translateX(0)';
  current = index;
  initPage(index);  // 触发当前页初始化
}

// 手势翻页
gesture.onSwipeLeft(() => current < 14 && goTo(current + 1));
gesture.onSwipeRight(() => current > 0 && goTo(current - 1));
```

### 核心技术点

| 功能 | 实现方式 |
|------|----------|
| 固定布局 | `width:640px; height:1008px` + `transform-origin: top left` 缩放适配屏幕 |
| 翻页 | CSS `translateX` + swipe 手势 |
| 滑动开门（P2） | `touchmove` 监听水平位移 → 两半门 `translateX` |
| 筋度/温度滑块（P5/P7） | `<input type="range">` + `oninput` 切换图片帧 |
| 360° 旋转（P11） | 序列帧 + `touchmove` 切换图片索引（降级方案：CSS `rotateY`） |
| 质检小游戏（P9） | DOM 点击检测 + `setInterval` 倒计时 |
| Slogan 动画（P13） | CSS `@keyframes` + `animation-delay` 逐字弹跳 |
| 海报生成（P14） | HTML5 Canvas 多层合成 + `toDataURL()` + `<a download>` |
| 音效控制 | `AudioManager` 类封装 `<audio>` + 全局静音 toggle |
| EPUB 脚注弹窗（P4） | `epub:type="footnote"` + `<aside>` 原生实现 |
