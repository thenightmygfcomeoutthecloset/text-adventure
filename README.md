# 异界卷 · 文字冒险

> 当前版本：v0.7.5「A11y重构与状态恢复增强」
> 线上体验（GitHub Pages）：https://thenightmygfcomeoutthecloset.github.io/text-adventure/

纯静态前端自由文字冒险游戏。AI 叙事引擎由 DeepSeek Chat API 驱动，支持 Supabase 云端账号跨端同步存档与离线游客模式。

---

## 🌟 核心特色

- **28 种世界观设定**：
  - **男频世界**：奇幻仙侠、传统玄幻、武侠江湖、科幻、末日废土、赛博朋克、蒸汽朋克、无限流、都市修真、都市高武、历史古代、赘婿、战神、重生崛起、悬疑灵异
  - **女频世界**：宫斗宅斗、霸总、重生复仇、禁忌情缘、都市异能、西幻史诗、克苏鲁、古言脑洞、玄幻言情、萌宝、年代文、双男主、马甲
  - **自由穿越与定制**：支持上传本地小说 txt 解析世界观并穿越进入，或自由输入背景书写定制世界
- **深度角色塑造与命格系统**：10 种隐藏命格、多维度身世与属性塑造、个性化背景生成
- **D20 命运检定与数值驱动**：动作与风险关键词判定、D20 骰子判定（大失败/失败/成功/大成功）、角色动态数值体系（HP/精力/理智/攻击/防御）
- **沉浸式交互系统**：世界年表动态演进、角色羁绊网络、随身物品使用、成就解锁、足迹地图、回退与重新生成
- **安全与云端架构**：
  - 本地 API 密钥通过 Web Crypto (PBKDF2 + AES-GCM) 浏览器本地加密存储，不经过第三方中间服务器
  - Supabase Auth + PostgreSQL 云存档同步，支持手机号/邮箱快速注册，亦支持完全免登录的离线游客模式

## 💾 存档与身份机制说明

本项目采用完备的双层存档系统与身份隔离体系：

1. **槽位映射规范**：
   - `slot = 0`：**自动存档专属槽位**。系统在玩家行动完成后自动同步（角色死亡状态不会覆盖正常可玩的自动存档）。
   - `slot = 1 ~ 10`：**手动存档槽位**。玩家在「存档管理」界面中保存的 10 个独立槽位，与自动存档完全隔离，互不覆盖。
2. **多身份数据隔离**：
   - **游客模式**：无需注册，开局即自动分配唯一的持久化游客标识（`guest:<id>`），自动存档与手动存档均带有作用域前缀，多游客或多设备不会混淆。
   - **云端模式**：登录后切换为 `cloud:<user_id>` 作用域，享有跨设备云同步和本地双重备份。
   - **平滑迁移**：游客在注册/登录云端账户时，系统会自动检测并提示将本地游客进度迁移至云端。迁移采取**保护策略**，若云端对应槽位已有数据，则保留云端旧数据，不暴力覆写，同时本地游客存档原样保留作为兜底。
3. **并发安全与状态快照**：
   - 云端保存操作在客户端按用户和槽位执行 FIFO 队列串行化处理，消除因异步网络延迟引发的写入乱序竞争。
   - 回退一步（Undo）与重新生成（Regenerate）采用回合前全状态快照恢复，能够精确还原数值（HP/MP）、物品背包、NPC羁绊、探索足迹与主线进度，避免旧回复产生的状态被重复叠加。

## 🚀 部署与运行

### 1. GitHub Pages 部署
本项目为纯静态结构，GitHub Pages 部署源直接配置为 `master` 分支根目录（`/`）。提交推送至 `master` 后，GitHub Pages 自动部署生效。

### 2. 本地 HTTP 服务运行（推荐）
在仓库根目录下运行静态服务器：
```bash
# Python 启动本地服务
python -m http.server 8080
```
在浏览器中打开 `http://localhost:8080` 即可开始冒险。

### 3. 浏览器直接双击运行
直接在浏览器中打开根目录下的 `index.html` 即可运行。

## 🛠 Supabase 部署与环境要求

如需自建或配置云存档 Supabase 数据库：
1. 打开 Supabase 控制台的 **SQL Editor**，执行仓库中的 `supabase/schema.sql`；
2. ⚠️ **关键配置（必做）**：
   本项目将中国大陆手机号转换为虚拟邮箱（`手机号@phone.user`），走 Supabase Email/Password 注册。
   **必须在 Supabase 控制台：Authentication → Providers → Email 中，将 "Confirm email" 设置为 OFF（关闭）**。
   若未关闭，新注册用户无法立即获取 session 导致注册后无法直接登录云端。
   *(注：此方案为便捷免短信验证码方案，仍需至少6位密码，不校验手机所有权)*。
